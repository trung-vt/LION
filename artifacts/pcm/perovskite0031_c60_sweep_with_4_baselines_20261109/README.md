# Perovskite 0031: UTV C60 scaling with four matched baselines

One-page PDF containing ground truth, zero-fill, SPGL1-BPDN,
PnP-ADMM-tuned-5, GS-PnP-tuned-5, and 12 UTV C60 reconstructions.
Rho is in ascending order: 0.01, 0.05, 0.1, 0.3, 0.4, 0.45, 0.5,
0.55, 0.7, 0.9, 0.95, 1.0.

Every reconstruction uses the same frozen 20% multilevel Hadamard acquisition
with NPL-default noise. Source array MSE values and frozen acquisition hashes
have been verified against the 450-image benchmark. No new baseline
reconstructions or measurements were simulated.
